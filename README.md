# 🌐 Portfolio Personal

Este es el repositorio de mi portafolio personal, diseñado para mostrar mi experiencia, habilidades y proyectos destacados como desarrollador web. El portafolio está construido utilizando tecnologías modernas y sigue las mejores prácticas de diseño y desarrollo.

## 🚀 Tecnologías

Este proyecto está desarrollado utilizando:

- **HTML5** y **CSS3**: Estructura y estilos básicos.
- **TailwindCSS**: Framework para estilos utilitarios.
- **Vue.js**: Framework JavaScript para componentes dinámicos.
- **Firebase**: Para la integración de servicios backend, como autenticación o almacenamiento.
- **JavaScript/TypeScript**: Funcionalidad y tipado estático.

## 🎨 Características

- **Diseño moderno**: Totalmente responsive para cualquier dispositivo.
- **Interactividad**: Animaciones fluidas y navegación dinámica.
- **Tecnologías destacadas**: Representación visual de las tecnologías que domino, con colores e íconos personalizados.
- **Proyectos destacados**: Una sección dedicada a proyectos reales y en producción.
- **Contacto directo**: Formulario integrado para que puedas contactarme fácilmente.

## 📂 Estructura del proyecto

```plaintext
portfolio/
├── public/          # Archivos públicos
├── src/             # Código fuente
│   ├── assets/      # Imágenes, íconos y recursos estáticos
│   ├── components/  # Componentes reutilizables
│   ├── styles/      # Estilos globales y de Tailwind
│   ├── views/       # Vistas principales del portafolio
├── README.md        # Este archivo
├── package.json     # Dependencias del proyecto
├── tailwind.config.js # Configuración de TailwindCSS
└── vite.config.ts   # Configuración de Vite para desarrollo
```
